# 🚀 Space Shooter (Pygame)

Um jogo **Space Shooter** simples desenvolvido em **Python** utilizando a biblioteca **Pygame**.  
O jogador controla uma nave espacial e deve derrotar ondas de inimigos enquanto evita colisões e tiros.

## 🎮 Gameplay

- Controle uma nave espacial
- Atire lasers contra inimigos
- Enfrente ondas progressivas de naves inimigas
- Sistema básico de vida e colisão

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Pygame**

## ▶️ Como Executar o Jogo

### 1️⃣ Pré-requisitos

- Python 3 instalado  
- Pygame instalado

Instale o Pygame com:

```bash
pip install pygame
```

### 2️⃣ Executar

Dentro da pasta do projeto:

```bash
python main.py
```

## 🎮 Controles

- **A / D** → Mover a nave para esquerda/direita  
- **W / S** → Mover a nave para cima/baixo  
- **Barra de Espaço** → Atirar laser  

## 🧠 Funcionalidades Implementadas

- Movimento do jogador
- Disparo de lasers
- Inimigos com cores diferentes
- Colisão entre lasers e naves
- Sistema de vidas
- Fundo animado

## 📦 Assets

Todos os assets gráficos (naves, lasers e fundo) estão localizados na pasta `assets/`.
